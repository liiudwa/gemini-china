## 方式五：API 调用（开发者）

如果你是开发者，想把 Gemini 集成到自己的程序、网站或自动化流程中，可以使用 API。

### 优点

- 灵活性高

### 缺点

- 需要一定编程知识
- 需要处理配额和调用限制
- 需要做好错误处理、日志记录和密钥保护

### 怎么用

#### 第一步：获取 API Key

有两种常见方式：

**方式 A：官方 API**

- 访问 Google AI Studio
- 创建 API Key
- 按官方文档配置调用

**方式 B：第三方 API 接入**

- 访问 [https://chat.aimirror123.com/](https://chat.aimirror123.com/)
- 查看平台支持的模型和调用方式
- 创建或获取 API Key
- 按平台文档配置接口地址

#### 第二步：配置代码

以下示例仅用于说明调用结构，具体 SDK、模型名和接口地址请以服务平台文档为准：

```python
import google.generativeai as genai

# 配置 API Key
genai.configure(api_key="your-api-key")

# 创建模型
model = genai.GenerativeModel("gemini-3.1-pro")

# 生成内容
response = model.generate_content("Hello!")
print(response.text)
```

#### 第三步：调用 API

在代码中调用 API，就像调用普通函数一样。生产环境建议使用环境变量保存 API Key，并增加超时、重试和异常处理。

### 适合谁

- 开发者：需要集成到应用
- 企业：需要批量处理任务
- 高级用户：需要自动化工作流

### 成本

官方 API 和第三方 API 的价格、免费额度及模型范围可能不同，请以对应平台的实时价格页面为准。

## 常见问题

### Q1：镜像站安全吗？

A：不同平台的数据处理方式不同。使用前建议阅读隐私政策，不要提交身份证件、银行卡信息、账号密码和其他敏感资料。

### Q2：镜像站会一直免费吗？

A：免费额度、试用规则和服务价格都可能调整，请以平台当前页面说明为准。

### Q3：镜像站和官方有什么区别？

A：镜像站属于第三方访问入口，模型版本、额度、隐私政策、稳定性和功能范围可能与官方服务不同。

### Q4：可以同时用多种方式吗？

A：可以。日常对话可以使用镜像站，多模型对比可以使用聚合站，开发测试则可以使用 AI Studio 或 API。

### Q5：哪种方式最省钱？

A：先使用官方免费配额或平台提供的试用额度，再根据实际需求选择付费方案。具体成本取决于使用频率和模型类型。

### Q6：哪种方式最稳定？

A：官方服务通常更容易获得完整的产品支持，但实际体验还会受到地区、网络和账号状态影响。

### Q7：开发者应该选哪种？

A：如果只是测试，可以使用 AI Studio；如果要集成到应用，可以选择官方 API 或 [API 接入入口](https://chat.aimirror123.com/)。

### Q8：镜像站支持所有模型吗？

A：不同平台支持的模型不同，请以平台当前模型列表为准。

### Q9：多模型聚合站和 Gemini 镜像站有什么区别？

A：Gemini 镜像站主要面向 Gemini 系列模型；多模型聚合站通常支持多个 AI 厂商的模型，适合需要横向比较和统一使用的用户。

### Q10：AI Studio 的免费配额够用吗？

A：对于轻度使用、学习和测试通常够用；如果需要高频调用或生产环境服务，应提前查看配额和计费规则。

## 使用技巧

### 技巧 1：选对模型

不同任务可以选择不同模型：

- Gemini 3.1 Pro：复杂任务、编程、数学和分析
- Gemini 3 Pro：日常对话、写作和总结
- Gemini 3 Deep Think：深度推理和算法问题
- Gemini 2.0 Flash：快速响应和简单任务

### 技巧 2：优化 Prompt

好的 Prompt 通常能让结果更稳定。

不好的 Prompt：

```text
帮我写代码
```

更好的 Prompt：

```text
用 Python 写一个数据分析工具：
- 读取 CSV 文件
- 支持多种统计分析
- 生成可视化图表
- 导出 PDF 报告
```

### 技巧 3：分步骤完成复杂任务

1. 先让 AI 理解需求。
2. 再让 AI 设计方案。
3. 最后让 AI 实现并检查结果。

### 技巧 4：多试几次

如果结果不满意，可以补充背景、限制条件、输出格式和示例，再重新提问。

### 技巧 5：保存好的 Prompt

遇到效果稳定的 Prompt，可以保存到自己的提示词库，下次直接复用。
